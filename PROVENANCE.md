This repository grants no QNX rights to anyone.

This repository publishes methodology and code only; quantitative results are not committed (results/** force-ignored by .gitignore); re-test methods in [bench/](bench/) and [docs/](docs/).
- **The mkqnximage template skeleton is not committed**: what is tracked under [qnx/build/local/](qnx/build/local/) is only our configuration delta on top of the mkqnximage-generated skeleton (the [local/options](qnx/build/local/options) delta file, the credential generation script and its README). The template skeleton generated by mkqnximage init (default options, snippets/*, valgrind.files, part.info, etc.) is QNX SDP-derived content and is not committed - every user runs `mkqnximage init` with their own SDP 8.0 to generate the skeleton, then applies this repo's delta files.
